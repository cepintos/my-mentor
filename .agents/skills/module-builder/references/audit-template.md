## Audit checklist

- [ ] Goal alignment: every unit serves a selected goal.
- [ ] Dependency integrity: every concept has its prerequisites.
- [ ] Forward continuity: each unit prepares the next.
- [ ] Backward traceability: every final requirement traces back.
- [ ] Redundancy: no needless repetition.
- [ ] Difficulty progression: gradual.
- [ ] Practicality: the learner builds or diagnoses something real.
- [ ] Assessment: evidence of mastery exists.
- [ ] Scope: realistic size.
- [ ] Local coverage: every REQUIRED concept has a local reference page created no later than its first use.
- [ ] Scaffold curve: starts at 5 for a new track, never drops more than one level between modules.
- [ ] Tooling: every command a module runs is declared in `commands`, and the doctor checks every program those commands need.
